# Funmilayo Dorcas | Digital Marketer & Paid Ads Landing Page

A high-converting, modern portfolio and lead generation landing page built with **React.js**, **Tailwind CSS**, and **Vite**, tailored specifically for sponsored ad management across **Facebook**, **Instagram**, **TikTok**, and **WhatsApp**.

---

## 🌟 Key Features

1. **High-Converting Hero Section**:
   - Compelling value proposition and key authority stats ($750K+ ad spend managed, 4.8x average ROAS).
   - **Interactive Live Campaign Monitor**: Lets visitors toggle between Meta (FB & IG), TikTok, and WhatsApp campaigns to view simulated real-time ROAS, CTR, and CPC metrics.

2. **Dedicated Platform Modules**:
   - **Facebook Ads (Meta)**: Custom Audiences, Lookalike 1-5%, CAPI pixel tracking, native lead forms.
   - **Instagram Ads**: Scroll-stopping Reels (9:16), carousel slides, aesthetic creator whitelisting.
   - **TikTok Ads**: First 1.5-second hook testing, UGC creator formats, Spark Ads.
   - **WhatsApp Funnels**: Direct Click-to-WhatsApp sponsored ads, automated greetings, fast 1-on-1 closing.

3. **Interactive Ad ROI & Lead Calculator**:
   - Prospects can adjust monthly ad budget ($300 to $10,000+) and average order value sliders.
   - Displays estimated impressions, clicks, qualified leads, and projected net revenue.
   - 1-click **"Lock In This Strategy"** button pre-fills the contact form with their chosen budget.

4. **Proven Case Studies & Real Social Proof**:
   - Detailed breakdown cards with spend, revenue, and ROAS numbers.
   - Authentic 5-star client testimonials.

5. **Strategic 4-Step Process & FAQ Accordion**:
   - Walks prospects through Audit, Creative & Copy, Launch & Tracking, and Scaling.
   - Answers critical questions regarding budgets, creative production, and WhatsApp funnel setup.

6. **Direct Email Lead Capture Form**:
   - Fields: **Name**, **Email**, **Phone Number / WhatsApp**, **Target Platforms**, **Budget**, and **Comments**.
   - Submits directly to: **`oladipupofunmilayodorcas@gmail.com`**.
   - Includes anti-spam honeypot, form validation, and interactive celebration confetti on success.
   - Instant WhatsApp fallback button pre-filling the message with the client's information.

7. **Floating WhatsApp Quick-Connect Widget**:
   - Fixed bottom-right corner with pulse animation and proactive greeting tooltip.

## 🚀 How to Run Locally

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 3. Build for Production
```bash
npm run build
```
The optimized production bundle will be created in the `dist/` directory.

## 📧 Email Delivery Setup (FormSubmit.co)

The contact form is configured to send all client leads to **`oladipupofunmilayodorcas@gmail.com`**.

> **Note on First-Time Activation**:
> When you or a visitor submits the form for the very first time, FormSubmit will send a **one-time confirmation email** to `oladipupofunmilayodorcas@gmail.com`. Simply open that email and click the **"Activate Form"** button. After that single click, all future client submissions will immediately flow directly to your inbox with full client details (Name, Email, Phone, Budget, Platforms, and Comments).

## 🛠️ Tech Stack
- **Framework**: [React 19](https://react.dev/) + [Vite 8](https://vitejs.dev/)

- **Icons**: [Lucide React](https://lucide.dev/) + Custom Brand SVGs
- **Celebration Effects**: `canvas-confetti`
- **Form Delivery**: FormSubmit AJAX API
